# Murmur

在 Tasks 文件夹新建笔记，首行写 `- [ ] 标题`。在同一行用 ⏳ YYYY-MM-DD 和 📅 YYYY-MM-DD 设置计划日和截止日。下一段是详情。勾选和取消勾选会在下次同步时更新掌机。

在 Hearth 的 Tasks 卡片点任务标题，点详情底部的垃圾桶「删除任务」并确认。宽限期后旧任务可在 Archive 找回。主页 Favorites 列出已选的锁屏随记。点击 Favorites 标题可进入全部随记，用「在锁屏显示」复选框调整选择。

新录音和在 Memos 文件夹手写的随记默认不勾选。点 Favorites 进入「锁屏随记」，勾选后掌机下次同步时便会加入轮播。录音生成的笔记带有来源链接。

Templates 中提供任务和随记模板。可在 Murmur 内移动或重命名带 ID 的记录。保留 ID 属性，复制笔记来新建时要删掉原 ID。删除文件并经过宽限期会删除服务端记录。在本机 NTFS 上，移出同步目录的同卷文件可通过文件 ID 找回，服务会暂停该记录，直至移回。跨卷移动和云盘用复制加删除实现的移动，应在宽限期内移回管理目录。

同字段冲突时，本地版本保存在 Conflicts，当前记录显示服务端版本。核对后将需要的内容复制回当前笔记并删除冲突副本。远程删除的笔记在 Archive 可找回。要恢复为新记录，将副本移入对应目录并删除 ID 属性。
