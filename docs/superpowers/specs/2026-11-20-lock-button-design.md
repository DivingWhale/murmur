# Return to the lock screen

Holding OK for 800 ms on Today, Claude or MD opens the lit lock screen so the owner can see the clock. Holding NEXT on those screens sleeps immediately. A separate OK hold on the lock screen sleeps. Releasing the original hold must leave the clock visible.

Inside the picker, quick panel, settings and brightness screens, OK still goes back one level. On a sleeping device, pressing NEXT wakes to the lock screen.
